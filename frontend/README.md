# 💈 Barbería Denver — Módulo Frontend (React + Vite + Firebase)

Módulo cliente del sistema de agendamiento para **Barbería Denver**, desarrollado en React 19, Vite 8, Tailwind CSS v4 y Firebase.

- **URL Desplegada (Firebase Hosting):** [https://barberia-denver.web.app](https://barberia-denver.web.app)
- **Estética Visual:** Caricatura Clásica Vintage 1930s en Blanco y Negro (Fleischer Studios / Popeye / Cuphead).

Para la documentación completa del proyecto, arquitectura del monorepo, guía de base de datos Neon y despliegue del backend en Render, consulta el [README Principal del Proyecto](../README.md).

## Scripts Disponibles

```bash
# Desarrollo local
npm run dev

# Compilar para producción
npm run build

# Desplegar a Firebase Hosting
npx firebase-tools deploy --only hosting
```
